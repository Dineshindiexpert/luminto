# ✨ Luminto - Modern Web UI Design

A sleek, responsive, and high-performance web interface built with a focus on modern design aesthetics and clean code architecture.

## 🚀 Overview
Luminto is a frontend project that demonstrates advanced styling techniques using **SCSS** and **Bootstrap**. It features a modular design, ensuring responsiveness across all devices (Mobile, Tablet, Desktop).

## 🛠️ Tech Stack
*   **HTML5:** Semantic structure for better SEO and accessibility.
*   **SCSS (Sass):** Used for modular styling, variables, and nested hierarchies to keep the CSS maintainable.
*   **Bootstrap 5:** Leveraged for a mobile-first responsive grid system.
*   **Assets:** Optimized images and custom fonts for a premium look.

## ✨ Key Features
- **Responsive Layout:** Perfectly adapts to any screen size.
- **Custom SCSS Architecture:** Organized folder structure for styles (assets/scss).
- **Modern Components:** Styled buttons, navigation, and hero sections.
- **Fast Loading:** Clean code with minimal overhead.
